## 一、系统定位与演化

时间感知事件检索（EventRAG）→ 高价值内容按需建图（七类关系）→ 带证据流式问答。

## 二、当前架构（v3.1，`CodeV3/`）

### 2.1 流水线七阶段

```
ingest（两层去重+来源谱系）→ extract（27B 抽取，引文程序校验，长文分窗）
→ entity（规则规范化+seed 层级）→ vector（框架/证据/chunk/事件卡向量，4096 维）
→ resolve（同事件判别四分支：attach / create_provisional / judge / pending，
          时间片并行、片间屏障、主线程串行落库）→ assertion（追加账本+双时间选择+变化卡）
→ project（outbox→投影水位）
```

### 2.2 同事件判别核心（S(x,C) = 0.34·S_semantic + 0.26·P_same + 0.16·S_time + 0.14·S_entity + 0.05·S_location + 0.05·S_type）

- 召回四通道：ANN（质心+代表证据余弦）/ BM25 / 结构化（实体）/ 未投影补丁；
- S_semantic=质心余弦（BM25 词面分兜底）；**P_same=Jev choice 全候选概率分布**（一次调用）；
- 灰区（0.78-0.88 分带外）送 **Jev 双问**：choice（同事件/新事件/相关过程+全分布）+ noul（证据充分性）；
- 身份锚点/冲突规则推导留痕；高置信直通带需三重结构锚点（同类型+共享实体+时间重叠）；
- 铁律：不做传递闭包、簇间合并仅人工（merge_clusters 版本化可撤销）、无证据不编造。

### 2.3 检索与问答

- 文档检索：BM25 + dense 双通道 RRF → Jev 相关性重排；
- EventRAG 事件检索：事件卡 ANN + 实体结构化（家族一跳扩展）+ 事件卡 BM25 → 时间软分 → Jev 重排；
- 问答：查询分析（实体链接+时间窗+意图路由 current/evolution/as_of/exploration，规则式）→ 证据包 → 27B 流式生成（enable_thinking=false，引用角标）。

### 2.4 可复现机制（实测验证）

所有模型 IO（chat/embed/decisions）按内容哈希落 `llm_cache.db`（Jev 判定 11188 条缓存）；
embedding 另有向量缓存；`--reset` 重放同代际 **13/13 表指纹逐字节一致**（含判别留痕）；
首跑↔重放仅质心 BLOB 与留痕微差（首跑并发推理非逐位性，业务表全一致）。

## 三、模型体系与成本

### 3.1 三件套分工（判定权与生成权严格分离）

| 模型 | 端点 | 职责 | 关键参数 |
|---|---|---|---|
| qwen3.8-27b（vLLM tp4） | 10.10.21.216:8003 | 提及抽取 / 流式问答（**只生成不判定**） | enable_thinking=false（/no_think 无效已实测）；32 并发抽取 25 篇/分（GPU 聚合吞吐饱和） |
| qwen3-embedding-8b（vLLM） | 10.10.21.216:8001 | 向量召回（**只召回不判定**）：ANN/dense/S_semantic/事件卡 | 4096 维 L2 归一化；批量 0.3s/3条、缓存 0ms |
| Jev（typesafe/jev-1.13-20260917，OpenRouter decisions） | openrouter.ai | **全部判定**：P_same 分布 / 灰区判别 / 检索重排 | 非自回归并行采样；实测 p50 0.46s、$0.00004/次、~15 req/s 饱和；全量跑一遍 ≈ $0.5；输出免费（$0.042/M 输入） |

### 3.2 评测背书（为何这样分工）

五模型评测（262 条精确标注，2026-09-24）：Jev 事件核对 1.0 / 实体核对 0.966 / 层级分类 0.931，
唯一可担判定职责；生成模型判定面"宽容判官"（8B 细粒度伪造召回 0、事件 acc@0.5 仅 0.30）；
embedding 判定面"全拒型"（13 真实体相似度全 <0.5）；reranker 排序外无判定力；Laya 1024 token 硬截断不可用。

### 4.1 两代产线全量对比（同语料 4587 篇：v2 vs v3.1）

| 引文作废率 / claims 每提及 | 8.38% / 1.14 | **6.15% / 1.48** |
| 活跃簇 / 实体 / 过程 | 16890 / 12183 / 10892 | 9517 / 10069 / 7079 |
| 断言 / 双时间选择 / 变化卡 | 19536 / 15045 / 13128 | 16779 / 12099 / 6771 |
| 关系边 / 其中矛盾边 | 59906 / **2902** | 35187 / **1263** |
| 多来源簇占比 / 单成员簇占比 | 4.38% / 95.6% | **5.55%** / 94.5% |
| pending 提及 | 198 | **61** |
| 决策分布 | attach 723 / judge_attach 475 / create 13161 / judge_create **3729** / pending 198 | 298 / 401 / 9500 / **17** / 61 |

**Jev 五维二次评判**（同评判器、同规则、固定 seed）：

| 维度 | v2 | v3.1 | 结论 |
|---|---|---|---|
| A attach 精度（并方向正确性） | 0.850 | **1.000** | v3.1 零误并 |
| B 簇纯度（多成员簇内一致性） | 0.750 | **0.954** | 大幅提升 |
| C 过分裂率（该并未并，分方向） | 0.400 | 0.433 | **持平——两线共同短板** |
| D 断言忠实度（原文支持率） | 0.900 | **0.967** | 事实层更干净 |
| E 检索 mAP@5（12 固定查询，同算子） | 0.817 | 0.817 | 持平 |

**行为机理**：灰区送判量 4204→418（-90%）——reranker 相关分虚高把非同事件推进灰区再被
8B 宽容判官放行（两层虚高叠加=15% 误并）；Jev 概率诚实，不该进灰区的根本不进，且判别成本降 90% 精度反升。

**抽取专项**（27B 少抽的 43% 是什么，31 条 Jev 逐条评判）：8B 独有提及 61% 真实 / **39% 碎片噪声**
（典型：一篇被拆 6-7 条"提供××服务"碎片）；换算两线真实事件量相当（~1.1 万 vs 1.03 万），27B 少漏约 17% 边缘事件。

### 4.2 过分裂根因剖析（12 对"该并"逐对回溯留痕）

| 死因 | 占比 | 说明 |
|---|---|---|
| R1 召回未相遇 | 42% | 候选池里没有对方簇（hub 实体 LIMIT50 行序截断 / 实体变体未归一 / 留痕 top10） |
| R5 同日时间片隔离 | 42% | 在线模拟固有：同日首报互不可见各自成簇 |
| R6 错并第三方 | 17% | 另一类问题 |
| 低分闸门 / 硬过滤 / 判别器判错 | **全部为 0** | **判别层零责——换判别器无效，病在召回结构** |

对策分级（依据 2024-2026 文献调研）：小改（blocking 复合键+实体归一+全池留痕）；
中改（按天批次簇间合并 pass）；大改（L1 表示适配 × L2 判定蒸馏 × L3 周期全局 canonicalization）。

### 4.3 判定基线（ml/benchmark，1000 对分层金标，Jev 预标版待人工复核）

| 判别器 | AUROC | acc@最优阈 | 灰带 AUROC | 灰带 ECE | 与 Jev 一致率 |
|---|---|---|---|---|---|
| Jev（teacher） | 0.9995 | 0.991 | 1.000 | 0.102 | — |
| 通用 embedding-8b | 0.9774 | 0.934 | 0.951 | **0.563** | **0.657** |

读数：通用 embedding 排序尚可但校准灾难（分数不能当概率用）——L1 微调目标：
ECE→0.15 内、一致率→90%+。分层预标：pos 层 Jev 判同 65% / neg 层 0 / **灰带层 15.7%（过分裂活体测量）**。
