# 训练档案：v1 → v8 五版迭代、连崩诊断与三条数据定律

> 完整记录 Event Same-Judge ZH 的训练历程——包括三代连崩的完整诊断链。
> 这些教训比最终成绩更有价值：它们是"数据飞轮"式迭代（每代 40 分钟：
> 改数据 → 训练 → 评测 → 诊断）的实证产物。评测口径见 [benchmark-protocol.md](benchmark-protocol.md)。

## 0. 任务设定

学生 = cross-encoder（输入两个事件文本 → P(同一事件)），教师 = 商业判定模型 API
（概率输出）。蒸馏目标不是省钱（教师全量调用仅约 $0.5/遍），而是：
**延迟 100×**（0.46s → 2-5ms）、**吞吐解锁**（万级簇对全量打分的使能器）、
**版本确定性**（对冲教师涨价/停服/漂移风险）。

## 2. 关键节点复盘

### 2.1 v1→v2：数据配比 > 一切（第一次验证）

v1 正对 75% 来自同源转载对（字面高度相似），学生学成"措辞像 = 同事件"。
把转载对降采样到 35%：pos 层 0.655 → 0.727——**这个提升超过之后任何模型升级的贡献**。

### 2.2 v3：4B 容量证伪

容量十倍的 decoder 式 reranker（官方 yes/no 模板 + LoRA + 梯度检查点）AUROC 仅持平
（0.914），pos 层反降、校准更差。结论：**瓶颈不在容量，在教师噪声上界（师生一致率
理论极限 ~0.9）与正对多样性**。这条结论省下了后续所有"换更大模型"的弯路。

### 2.3 v4-v7：三代连崩与诊断链（本档案最有价值的部分）

症状：v4/v5 阈值漂到 1.0、一致率跌到 0.30、输出饱和（sigmoid 全 ≈1.0）、
温度校准 LBFGS 卡死（梯度消失）。

诊断链（每代一个假设 → 训练 → 评测 → 证伪/证实）：

| 假设 | 验证版本 | 结果 |
|---|---|---|
| ①"提纯"毁了软标签（一致对拉到 0.8+/0.2-） | v5 去提纯 | ✗ 未恢复 |
| ② 假负例污染（丢了 margin 过滤） | v6 加回过滤 | ✗ 仅部分恢复（0.797） |
| ③ 标签极端值饱和（簇对通道 Jev 标签 0.001-0.99 两极 → BCE 推 logit 至 ±∞） | v7 标签裁剪 | ✗ 未恢复（治标） |
| ④ **大通道淹没**（C1 簇对 3.2 万条模板腔摘要 vs 原配方 2 万——数量压倒后，模型学"样式"不学"判别"） | v8 回退 v2 配方仅叠加验证过的小增量 | ✓ **复活 0.909 + pos 新高 0.767** |

## 3. 三条数据定律（v4-v8 五代 200 分钟迭代换来的）

### 定律一：大通道淹没定律
新增数据通道若在**数量上压倒**原有配方（≳1 倍），其文本分布（本例：模板腔簇摘要）
会成为主导学习信号，模型学到"样式特征"而非任务判别。**扩产必须增量叠加
（新通道 ≤ 原配方 1/3）逐代验证**，与经典课程学习/数据混合文献的发现一致。

### 定律二：标签极端值饱和定律
软标签蒸馏时，若某通道教师标签呈两极分布（0.001 vs 0.99），BCE 会把对应 logit 推向
±∞——sigmoid 饱和、概率失去分辨率、温度校准梯度消失。**标签必须裁剪**（我们用
[0.05, 0.95]），但裁剪只治标：两极分布的通道本身（毒源）应回退。

### 定律三：合成改写是 pos 层特效药
用 LLM 生成"同一事件的另一家媒体报道"（保持主体/对象/时间/动作，仅改变措辞与详略），
**1500 条即把 pos 层 0.727 → 0.767**（历史新高），成本为零（自建 27B 生成）。
它直击"措辞多样同事件"这一结构性短板，且可无限扩产——是数据飞轮下一阶段的主力通道。

## 4. 原生置信度工程（本模型的特色）

判别器若只有排序力没有校准（通用 embedding：AUROC 0.977 / ECE 0.563），
分数不能当概率用，置信分带/级联路由全部失效。我们的三层保障：

1. **软标签蒸馏**：学生回归教师的概率而非 0/1 硬标签（校准能力的源头）；
2. **温度后校准**：验证集 LBFGS 拟合单一温度 T（发布版 0.824），ECE 收敛至 0.19；
3. **可靠性分桶随附**：评测协议输出 10 桶置信-实际正率数据，供下游持续监控漂移。

注意：v4-v7 连崩时温度拟合卡死（T≈1.16 但输出仍饱和）正是"校准依赖健康的训练信号"
的直接证据——定律二的另一面。
