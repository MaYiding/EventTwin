# EventTwin 升级率配方（生产阈值指南）

> 结论先行：**v2.3 (v26) 单模型，阈值 [0.20, 0.90]**（p≥0.90 自动 SAME，p≤0.20 自动 DIFF，
> 其余升级）。在两种流量画像上同时把升级率压到 2.7% / 4.3%（原 [0.1,0.9] 口径为 9.5% /
> 23.7%），而误并、漏并几乎分毫未动。无需任何模型集成。

## 为什么是 [0.20, 0.90] 而不是 [0.10, 0.90]

对级联系统，`[t_low, t_high]` 的带宽就是成本：带宽越窄，越多对被升级给贵的高级模型。
系统扫描 5 个模型（v23b/v24b/v25/v26/v28）× 两种流量画像后发现：

1. **升级率的大头堆在 DIFF 侧的 0.1–0.25 带**。v26 在这个分数区间的对里，生产流量
   5,168 对中真 SAME 只有 4 对（0.36%），金标 1,000 对中 1 对（0.41%）——把 t_low 从
   0.10 抬到 0.20 是近乎免费的收割。
2. **SAME 侧不能动**。t_high 低于 0.9 时，硬负例（文字高度相似但不同事件）开始被自动
   并入，误并率快速翻倍（v26 在金标上 0.9→0.7：FM 2.77%→2.9%+，越低越糟）。
3. 早期分析中"抬 t_low 会把漏并率推到 10%+"的结论**是评测集标签 bug 造成的假象**
   （见文末"lineage 教训"）。修正后 v26 低分带的可靠性远超此前认知。

## 后续：v29（lineage 清洗重训，内部代号，v2.4 候选）

清洗 448 对 lineage 错标后同配方重训，模型显著更果断、校准更好（ECE 0.0569 历代直判
最佳），判别力持平（AUROC −0.3pt，跑次方差量级）。同一配方表追加 v29 行：

| 配方 | 生产画像 (n=5,168)¹ | 金标难例集 (n=1,000)² |
|---|---|---|
| | 升级率 / 误并 / 漏并 | 升级率 / 误并 / 漏并 |
| v29 [0.10, 0.90]（默认） | 4.14% / 0.42% / 0.09% | 4.00% / 3.29% / 0.83% |

v26 与 v29 的取舍：**v26 判别力/误并最优**（FM 2.77% vs 3.29%，AUROC +0.3pt），**v29
升级率再降约一半且校准最佳**。误并敏感（自动并闸门）选 v26，成本敏感（尽量不升级）
选 v29——两者阈值结构相同，切换零成本。

## 误并防线：双模型 AND 门（2026-10-09 补充）

若误并预算趋零，在任意单模配方外套一层**自动并双模否决**（两模型都 ≥0.9 才自动 SAME，
任一模型 ≤t_low 即自动 DIFF）：

| 配置 | 生产画像 esc/FM/miss | 金标 esc/FM/miss |
|---|---|---|
| v26 单模 [0.2,0.9]（对照） | 2.69% / 0.42% / 0.36% | 4.30% / 2.77% / 0.41% |
| **v26+v30 AND 并 / v26 拒 0.2** | **3.27% / 0.22% / 0.36%** | **5.20% / 2.37% / 0.41%** |
| v26+v30 AND 并 / v30 拒 0.2 | ~2.4% / ~0.3% / ~0.6% | 3.60% / 2.37% / 1.24% |

误并砍半只花约 0.6-0.9pt 升级率；漏并不动。实现上第二模型只需在首模型 ≥0.9 的对上
运行（生产流量中约 25-30% 的对），增量算力可控。

### v30（边界数据实验，内部）与残余误并的本质

v30 = 矛盾标签清洗（77 对）+ 9,212 对定向边界合成数据重训：升级率/校准延续 v29 水平
（[0.2,0.9] val 2.03%/金标 2.00%），但金标 FM 3.69% 未反降微升。人工复核金标残余误并对
（21-26 对）发现其中相当部分是**标签争议对**（同日同城"发布会 vs 上市"两种口径、
Optimus/TeslaBot 别名异市场报道、可转换/可换股票据港美双公告）——按帧严格口径判"不同
事件"，按现实指向判"同一事件"。这类对的"正确"边界取决于产品定义，无法靠训练数据消
除；AND 门是目前唯一能系统性压住它们的手段。

## 被否决的路线（都有实测数字，勿重复踩）

| 路线 | 结果 | 为什么不行 |
|---|---|---|
| 双模型共识（任一≥0.45 并 / 双≤0.15 拒） | 生产画像升级率 5.13%，但金标 FM 2.77%→7.77% | 硬负例恰好落在两模型的中分带，"任一"规则放大最差模型 |
| 三模型中位数 [0.2,0.6] | 金标 4.0%/FM 3.03% 优秀，但生产画像漏并 10.8% | 中位数把 v24b 独有的低分可靠性稀释掉 |
| 保序回归再校准 | 修漏并不修升级率，同误并下升级率不降反升 | 校准移动的是分数单调映射，灰带总量不变 |
| 级联 v24b 主判+v23b 复核灰带 | 生产画像 2.8%，金标 FM 7.6% | 复杂度换来的仍是 v24b 的硬负例弱点 |

单模型 v26 宽 DIFF 带在两个画像上同时占优，是唯一不需要"按流量画像切换配方"的方案。

## lineage 教训（数据质量）

val/train 中 `lineage` 通道（同主体事件谱系对）有 452 对被标为 SAME(≥0.9)，抽检全部为
**同主体不同事件**（如"完成融资 vs 计划 IPO"、"财报 vs 单品销量"），按本项目数据定律应
为 DIFF。这些错标对把各模型在低分带的"漏并率"污染了 3–8 倍，一度使阈值研究得出
"DIFF 侧不能动"的错误结论。教训：

1. 分带指标（漏并/误并）必须按数据通道分解后再下结论——本次若不分解，会直接错过
   全部升级率收益；
2. 评测集里任何通道的标签都应过一遍与训练集同强度的构造校验；
3. 训练集中 279 对 lineage=1.0 毒样本已定位，v29 训练前需清洗（重标为 0.05 或删除）。
