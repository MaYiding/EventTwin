## v1.2 的取舍（如实）

v1.2（内部 v10a，LS+R-Drop+EMA）在四配置海选中以 7/8 指标胜出：pos 历代最高（0.847）、
灰带 acc 最高、ECE 较 v1.1 修复（0.302→0.261）、**高置信带误并率 0% + 漏并率 3.7%**
（分带安全性历代最佳）——是最安全的级联第一级。代价：标签平滑使分数整体保守，
70% 流量落灰带（需第二级），且 neg 层最优阈 acc 降至 0.945（对中阈值二分类用户有感）。
**三版并存**：v1.2（main，安全优先）/ v1.0（tag，独立判定最优）/ v1.1（tag，已被 v1.2
取代、保留复现）。v1.3 方向：双头蒸馏或双模型路由，兼得判别力与分带安全。

## v1.1 的取舍（如实）

v1.1 是**方向性升级而非全面升级**：主攻的 pos 层（措辞多样同事件）+7pt 达成，但总体
AUROC（-1.5pt）、灰区排序与 ECE 弱于 v1.0——两版同时保留（HF main = v1.1，tag = v1.0），
模型卡内有逐项对比与选型建议。v1.2（内部 v10）以『两者兼得』为验收门禁。

## 为什么内部 v4-v7 不发布

三代连崩（AUROC 0.67-0.80，输出饱和）是数据配方错误的产物（大通道淹没 / 标签极端值
饱和），其价值在诊断链与三条数据定律（见训练档案），而非权重本身。保留完整档案、
不污染版本线，是对用户负责的做法。

## 版本号规则

- **MAJOR.MINOR**：MINOR = 数据配方升级（同一基座重训），MAJOR = **换基模或代际跃升**（v2.0 触发条件：4B decoder 新基座 + 总体 AUROC +5.4pt）；
- 每个公开版本的训练数据、超参、温度值在 Model Card 与 EventTwin-Data 中同步冻结；
- 模型卡中的"温度（T）"是版本的一部分——换数据重训必须重新校准并更新。
