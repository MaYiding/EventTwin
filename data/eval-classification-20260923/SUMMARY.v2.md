# 四模型评测报告 v2（通用场景 · 规则前置 · 内容归档）

2026-09-23。模型：Jev（typesafe/jev-1.13-20260917，OpenRouter decisions）；qwen3-8b、qwen3-reranker-0.6b、qwen3-embedding-4b（本机 llama.cpp）。v1 报告与全部 v1 数据保留为 `*.v1.*`。

## 1. 三个任务在测什么（各一例）

**实体核对（29 个）**——判断实体是否在文中出现。例：`Apple Inc.` 全称只在案件名出现一次，Jev 给 0.98；伪造拼写 `Venmon`（真值 Venmo）给 0.03（v1 曾给 0.49，规则前置后修正）；知识陷阱 `Tim Cook`（Apple CEO 但文中未提）0.03、`iPhone 17`（文中只有 16 系）0.03——四组：在文(13)/无关(6)/相近不在(5)/特别相近伪造(5)。

**事件核对（40 声明 × 5 问）**——四元组分程度伪造后核对。例：听证会日期 02-24 改成 **02-25**，Jev time 维 0.03 抓到；"总额 $95"冒充"$250M 和解金"的声明，Jev overall 判否而 8B 漏放（给 1.0）。

**层级分类（300 条长文 / 253 叶子 / 352 节点，最深 4 层）**——例：*《字节加入企业办公 Agent 大战：发布"豆包工作"》* → `软件与AI/大模型与AI应用/产品发布/软件与服务`。语料为 clean 目录 30 家公司中文新闻。

## 2. v2 对评测的修正（为什么重跑）

v1 错误分析（详见 SUMMARY.v1.md 附录结论）发现多数"错误"是评测自身的問題，v2 针对性修正：

| v1 问题 | v2 修正 |
|---|---|
| 答案按公司主行业（字节=平台、华为=电子），文章写别的业务就必错 | **按文章内容归档**：三段式领域规则（标题档→正文档标题→正文档），v1 点名的 15/16 案例全部修正（字节文生视频→AI、B站游戏部→游戏、华为芯片→半导体、比亚迪刀片电池→动力电池……） |
| "发布会带售价/发布财报/投资某地建厂/鸿蒙智行"等关键词陷阱 | 平局规则：发布带售价→产品发布；发布财报→财报与业绩；投资建厂→产能与扩张；品牌名不改硬件属性；高管落马→法律与监管 |
| 早参/行情 roundup 等无唯一答案样本 | 丢弃 185 条简报与 158 条多信号两可 |
| 类别不够通用 | 新增 L1 机器人与智能制造、其他与跨界（兜底单叶）；L2 金融与支付、云与企业IT；L3 财报与业绩、产能与扩张。体系 180→253 叶子，仍偏通用——遇到未知领域语料时"其他与跨界"承接，不至无处可归 |
| 模型只知道类目名，不知道判定边界 | **判定规则前置**：8 条平局/边界规则写进四个模型的提示词（Jev instructions+选项描述、8B 每层问题、rerank/embedding 的叶子描述），如"行业按内容不按公司主业""上限≠固定值""拼写相近≠同一实体" |
| 事件任务 c01 时间含推断年份 | 改为"今年早些时候宣布"（与原文相对时间一致） |

## 4. 表观分之外：错误归因（关键）

规则标注不可能完美，表观分仍低估模型。对 Jev 全部 56 条 L1 错误逐条人工判读（标题+双方路径）：

| 归因 | 条数 | 说明 |
|---|---|---|
| 参考答案错/模型更合理 | **30** | 例：小米 YU7 发布被规则回退标成"消费电子"（Jev 判新能源汽车，对）；中芯国际财报被标"新能源汽车"（Jev 判半导体，对）；OPPO A3 Pro 发布被标"半导体" |
| 真两可（多方合作/跨界/研报） | 25 | 例：荣耀×京东战略合作、长城×宇树合作、券商行业评论——无唯一正确答案 |
| **模型真错** | **1** | 荣耀×字节"豆包手机"合作：Jev 判 AI 类，"手机与穿戴"更准 |

即 **Jev 的 L1 真实准确率 ≈ 91%～95%**（表观 81.3%）。其余三模型在同一批问题上同样被扣分（与 Jev 的 L1 错误重叠 40–49 条），8B/rerank/embed 另各有 23–26 条 Jev 答对而自己答错的独有错误——真实差距比表观更大。规则标注的残余噪声主要在"集团多业务 + 内容关键词歧义"，要彻底消除需人工标注（300 条工作量可控，可作下一步）。

## 5. v1 → v2 变化说明了什么

- **Jev 事件 97.5%→100%**：修掉 c01 推断时间 + 规则前置后满分；分维 time 40/40（±1 天全中）。
- **Jev 实体 Venmon 0.49→0.03**：判定规则显著压掉"拼写相近"灰区；代价是 Clarkson Law Firm（真在文中的实体）被误伤到 0.21——严格规则存在少量误杀，用 0.2/0.8 分带（灰区送审）可两全，最优阈下仍 100%。
- **分类表观分基本持平（59.0→58.7）但考卷更难**：类别 180→253、答案从"公司主业"改为"文章内容"、砍掉 ~340 条两可候选、四模型都拿到了判定规则。同分不同卷，且归因后 Jev 真实水平显著高于表观。
- **8B 实体 81.8→93.1%**（规则前置帮助明显），但仍栽在 Ryan Clark/Venmon 两个伪造陷阱（0.95 假阳）；事件校准依旧差（@0.5 仅 30%）。
- **rerank/embedding 结论不变**：相关性有信号（分类 top3 65%/56%），判定无信号（事件 AUC 0.51/0.43）。

## 6. 选型结论

| 场景 | 推荐 |
|---|---|
| 实体在文核对、事件字段核验 | Jev（0.5 阈值；追求零误杀用 0.2/0.8 分带+灰区送审） |
| 长文归档 | Jev top-3（74.7%）+人工确认；零成本场景用 8B 逐层下降（约 50%） |
| 候选召回/段落排序 | reranker（本职） |
| 语义检索 | embedding（本职） |
