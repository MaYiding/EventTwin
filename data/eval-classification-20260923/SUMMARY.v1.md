# Jev / qwen3-8b / reranker / embedding 四模型评测报告

日期 2026-09-23。模型：Jev（typesafe/jev-1.13-20260917，OpenRouter decisions 端点）；qwen3-8b、qwen3-reranker-0.6b、qwen3-embedding-4b（本机 llama.cpp，100.92.114.89:8081-8083）。

## 1. 三个任务分别在测什么

**实体核对**：给定实体和一篇文章，判断实体是否在文中出现（含简称、别名，不算仅字面相近的不同实体）。
> 例：对 Apple 和解报道问 "Apple Inc."——全称只在案件名 *Landsheft v. Apple Inc.* 出现过一次，Jev 给 0.98；伪造拼写 "Venmon"（真值是 Venmo）给 0.49，reranker 给 0.06。22 个实体分四组：在文中(8)、无关(5)、相近不在(4)、特别相近伪造(5)。

**事件核对**：把文章中的事件抽成四元组（发出者/承受者/关系/时间），对每个维度做不同程度的伪造，判断声明与原文是否一致。
> 例：听证会真值 2027-02-24，声明改成 **02-25（±1 天）**，Jev 的 time 维给 0.03（抓到）；8B 在 40 条里只抓到 25 条 time 伪造，"总额 $95 当作 $250M 和解金"这类金额混淆（c09）8B 判 overall=1.0（漏放）。40 条声明 × 5 问（整体+四维）= 200 问。

**层级分类**：给长文本选归档路径，文件夹体系最深 4 层。
> 例：*《比亚迪前 9 个月卖了 326 万辆车…》* → `新能源汽车/整车制造/价格与销量/销量数据`。测试集 300 条（clean 语料 30 家公司中文新闻，正文 ≥500 字），标注 = 公司→行业映射 + 标题关键词唯一命中，规则全在 build_dataset.py，可审计。

## 2. 分类体系与指标定义

**体系**（build_dataset.py 生成，taxonomy.json）：

| 层 | 含义 | 取值 |
|---|---|---|
| L1 | 行业 | 消费电子 / 新能源汽车 / 半导体 / 互联网平台 / 软件与AI（5） |
| L2 | 细分领域 | 手机与穿戴、整车制造、动力电池、电商零售、游戏……（15） |
| L3 | 事件类型 | 产品发布、价格与销量、专利与知识产权、资本与并购、合作与联盟、人事与组织、法律与监管、技术与研究（8） |
| L4 | 事件细分 | 仅 4 个 L3 有：产品发布→硬件/软件与服务；法律→诉讼/监管；资本→收购并购/投资融资；价格→调价/销量数据 |

共 **180 个叶子类别、441 个节点**；27% 的事件类型（合作、人事、技术、专利）天然只有 3 层。

**分类指标**：

| 指标 | 定义 |
|---|---|
| 叶子 acc@1 | 预测路径与真值**完全一致**（每层都对）才算命中 |
| acc@3 | 真值落在模型 top-3 候选内（8B 只输出单答案，无此项） |
| L1/L2/L3 acc | 该层的**边际准确率**：预测路径第 k 层 == 真值第 k 层即算对，与其他层的对错无关。**不是连乘、不是条件概率**——所以会出现 L3 84% 而叶子只有 59%（错在下层不影响上层计分） |
| L4 acc | **条件准确率**：只在真值有第 4 层的 193 条上计（分母 193，非 300） |
| 层级 F1 | 把路径拆成节点前缀集合（如 `新能源汽车`、`新能源汽车/整车制造`…）算 micro-F1 后取平均——给"部分正确"记部分分，衡量预测离真值有多近 |

**核对类指标**：acc@0.5 = 分数 ≥0.5 判"是"的准确率；最优阈准确率 = 扫全部阈值能达成的上限（衡量区分度，即"校准好就能到多少"）；AUC = 与阈值无关的排序质量。

## 4. 解析

1. **Jev 三项全胜，且是在中文语料上**（其主训练语言为英文）。分类 top-1 领先第二名 8B 十一个百分点，top-3 达 80.7%。
2. **8B 是最好的本地备选**，但"太宽容"：事件核对 @0.5 只有 25%，把阈值拉到 ~0.9 才到 77.5%——说明有区分度（AUC 0.86）但分数校准差，直接用会大量漏放伪造（c09 金额混淆判 1.0）。
3. **reranker/embedding 不能做判定**：事件核对 AUC 0.54/0.43（随机线以下），但对"相关性"有感觉——分类 top-3 63.7%/53.7%，够格当召回粗筛层。
4. **分类错误结构**：L3 事件类型四个模型都对 76~84%，**真正的困难在 L2（跨行业新闻）和 L4（收购 vs 投资、硬件 vs 软件）**。最大混淆对"产品发布↔价格与销量"部分是标注规则的固有模糊——例：*《售价 26.9 万元起 全新极氪 001 正式开启猎装 2.0 时代》*（T005），规则按"售价"标了价格调整，Jev 判产品发布/硬件，两个答案都站得住；这条对四个模型全部记为"错"。
5. **Jev 置信度有信息量但不是闸门**：判对均值 0.847 / 判错 0.691，conf≥0.8 自动收档精度 72.6%（覆盖 58%）——不足以全自动，适合 top-3 + 人工确认的流程。
6. 代价：Jev 分类 300 条共 $0.155；其余三个本地模型免费。

## 5. 选型建议

| 场景 | 推荐 |
|---|---|
| 实体在文核对、事件字段核验（判别器） | Jev，0.5 阈值直接用 |
| 长文归档初分类 | Jev 出 top-3 + 人工确认；预算为零时用 8B 逐层下降 |
| 候选召回 / 段落排序 | reranker（本职） |
| 语义检索特征 | embedding（本职） |

## 6. 复现

```
python3 build_dataset.py && python3 run_jev.py && python3 run_rerank.py \
  && python3 run_qwen8b.py && python3 run_embed.py && python3 run_extra.py \
  && python3 evaluate.py
```

run_jev / run_extra 需环境变量 OR_KEY（OpenRouter）。产物：taxonomy.json（体系）、testset.json（300 条）、results/*.json（四模型原始输出）、entity_event_tasks.json（实体/事件任务数据）、metrics.json（全部指标）。
