# 五模型评测报告 v3（262 条精确标注 · 扩充指标）

2026-09-24。模型：Jev（typesafe/jev-1.13-20260917，OpenRouter）；**Laya（laya-multilingual，100.92.114.89:8084 `/v1/systemone`，与 Jev 同协议）**；qwen3-8b、qwen3-reranker-0.6b、qwen3-embedding-4b（本机 llama.cpp）。v1/v2 过程与数据在 `SUMMARY.v1.md`、`SUMMARY.v2.md` 及 `*.v1.*` / `*.v2a.*`。

## 1. 本轮做了什么

1. **人工标注修正层**（apply_adjudication.py + adjudication.json，全程留痕）：对 Jev 全部 124 条叶子错误逐条判读（读标题与双方路径），在规则标注之上叠加人工结论——**69 条改标**（参考答案错，按文章内容修正）、**38 条剔除**（真两可/无合适类目/重复转载）、**16 条维持**（模型真错）。测试集 300→**262 条精确标注**。修正只改参考答案、不改模型输入输出，**对既有四模型重打分等价于重跑**；Laya 为全新推理。
2. **评测标准扩充**：宏F1（L3 类平衡，抗类别不均衡）、实体分组检出率（A在文/B无关/C相近/D伪造）、事件伪造严重度召回（细/中/粗三档）、事件分维对比、置信度分带精度-覆盖。
3. **新增 Laya**：与 Jev 完全相同的 systemone 调用（state + questions，noul/choice）。因其服务端硬截断 1024 token，全部请求在**客户端显式截断**：分类改逐层下降（每层一个小 Choice，正文截前 550 字，实测单请求最大 874 token）；实体分批（6 个/请求，正文 600 字）、事件每声明一请求（正文 500 字）。**以下 Laya 成绩即其 1024 token 输入约束下的最终结果**（暗截断的旧版留档 `*.v3flat.json` / `*_laya_flat`）。

修正示例（adjudication.json 内 69 条均有）：*《魏牌新车上市前夕营销团队动荡》* 规则按"上市"标了产品发布/硬件 → 改为**人事与组织**；*《网易游戏贪腐案开庭》* 规则标监管调查 → 改为**诉讼纠纷**；*《小米 YU7 正式发布》* 规则回退到公司主标签"手机与穿戴" → 改为**新能源汽车/整车制造**。

## 5. 实用结论

1. **判定类任务（实体在文/事件核验）**：Jev 唯一可选；0.5 阈值直接用，防"严格规则误杀真实体"（Clarkson 案）可用 0.2/0.8 分带+灰区送审。
2. **长文归档**：Jev top-3 98.9%（上界口径）+ 人工确认；本地零成本场景用 8B（0.767 / 宏F1 0.914，免费本地模型里相当能打）。
3. **8B 的能力边界**：粗判可用、细核不可用——细粒度伪造 0 检出、事件分数校准差（@0.5 仅 0.30），只能当预筛。
4. **Laya 的定位**：1024 token 输入是硬天花板——显式截断+逐层下降后分类叶子 14.5%、L1 48.5%（暗截断平面版为 0%），仍与 8B 相差 60 个百分点；实体"全收型"（A 组 10/13 但无关实体也放 5/6，AUC 0.47）、事件细粒度召回 0。只适合"短输入+少量选项"的轻量判断场景。
5. **reranker/embedding**：本职（召回/检索）之外只有排序信号（实体 AUC 0.945/0.644，分类 top-3 0.790/0.710），不要赋予判定权。
6. **Jev 置信分带（修正考卷）**：conf≥0.8 自动收档精度 96.8%、覆盖 71%；≥0.6 精度 94.1%、覆盖 84%——比 v2 时（72.6%/58%）可用性大幅提升，可作生产线闸门。

## 6. 三轮演化的启示

v1（公司主行业标注）→ v2（内容规则标注+判定规则前置）→ v3（人工修正标注）：每次表观分"暴涨"（8B 0.497→0.767）都来自考卷修正而非模型变化——**评测质量决定结论质量**。剩余不确定性：Jev 的 v3 分数为上界（69 条修正与其预测一致）；若需绝对干净的数字，下一步是对 262 条做独立于任何模型输出的双人盲标。
